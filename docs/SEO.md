# Buscadores, vistas previas y métricas

Meta description, canonical y Open Graph son etiquetas gratuitas. No requieren GitHub Student. Las 29 guías estáticas tienen texto y tablas de callouts; se descargan al visitarlas y no forman parte de la carga inicial del atlas. Cada guía enlaza al mapa interactivo. No se añaden reseñas, rankings ni datos estructurados ficticios.

robots.txt y sitemap.xml se generan con las URL publicadas. En GitHub Pages de proyecto, el robots.txt situado en /breach-r6-atlas/ no sustituye al robots.txt de la raíz del dominio: los rastreadores consultan https://guidufox.github.io/robots.txt. No se modifica otro repositorio para imponer reglas de dominio. El sitemap del proyecto puede enviarse directamente a Search Console.

Google Search Console es gratuito. Registrar una propiedad de prefijo de URL: https://guidufox.github.io/breach-r6-atlas/. Verificar mediante etiqueta HTML o archivo, conservando la prueba de propiedad. La cuenta de Google debe ser del responsable; nunca pedir su contraseña o códigos por chat. Si el acceso no se completa, el registro sigue pendiente y no se afirma que Google haya indexado la web.

Métricas elegidas: contador propio de visitas agregadas del servicio de salas, sin cookies, identificadores de visitantes, IP guardada en la tabla, query strings ni fragmentos. Cuenta vistas, no personas únicas. Respeta Do Not Track y Global Privacy Control. Se envía tras la carga principal y no incluye tácticas, búsquedas, invitaciones ni webhooks. Las estadísticas agregadas son públicas; no muestran los datos de una sala.
