BREACH — R6 ATLAS 1.3.0
Extract the ENTIRE ZIP. Open Abrir-Breach.bat or index.html in Edge or Chrome.
No installation or Internet connection is required. Keep the maps folder intact.
Choose English, Español or Português (BR) in the top-right language selector.

Map names: Ubisoft's Latin American Spanish / Brazilian Portuguese listings.
Callouts: R6Calls map-specific community dictionaries. Source segments are
separated by «·» and marked ≈; select a spot to see all three equivalents and
its provenance. These are community references, not a verified official room
name catalog. English references can be shown beneath translated names.

Search maps and callouts in any of the three languages, with or without accents.
Add team aliases to existing spots; create pins, routes, drawings and floor notes.
Adjust label size in Layers. Practice favorites; review spots return in-session.

Before updating, export a JSON backup from the previous app. Extract this ZIP
into the same folder, replacing its app files, then reopen the app. Import your
backup if needed. Old favorites, notes and drawings are supported. Data stays
in this browser; changing browsers or folder locations may require importing.

Sources and coverage are available under Fuentes y nombres / Sources and names.

NEW IN 1.2.0
Bomb site A/B selector, nearby callouts, per-site notes and site-scoped drawings.
Cross-floor pairs are supported. Site numbers follow the source, without guessed
official room names. Practice > Find the callout: click the documented location;
counts attempts and correct answers for the session. Reveals do not count as correct.
Share SVG, PNG, PDF and plan JSON. PNG previews notes; PDF/JSON retain full text.
Import plan JSON on another PC. Drawings for another revision are archived.
Map updates: run Actualizar-Mapas.bat with Internet, choose a newly revised map,
then import the .json.gz package in Maps. Preview before applying. Up to three
previous map revisions are kept in this browser, with rollback. Changed source
files archive old drawings; notes/favorites remain. Export your regular backup
and retain update packages before moving PCs. Map packages require IndexedDB.
GitHub Pages publication files are included; see PUBLICAR-WEB.md. Website update
checks use its own catalog, refreshed manually by the owner through GitHub Actions.

NEW IN 1.3.0 — APPROVED OPTIONS 16, 17, 21, 22, 24, 26
Plan > Notes: five player names, tasks, linked callouts and completion states.
Select a bomb site for site-specific tasks; otherwise tasks are per floor.
Site selection remains active when following a task to a different floor.
Editable per-site checklist, up to 40 items; reset clears completion marks.
Maps > Compare: before/after floor views and added/removed/renamed/moved callouts
plus bomb-marker changes. Other geometry and layers require visual review.
History > Recover drawings: select an archived drawing and destination floor,
click to translate its first point, review the purple preview, then explicitly
mark its position reviewed and add it. Original archives remain unchanged.
Share > Discord: editable team message, PNG and plan JSON; copy/download manually
or send to a chosen channel webhook with Internet. The webhook is never saved
or backed up. Success requires Discord confirmation; there are no automatic
retries. Check the channel before retrying an uncertain send. Combined files
are capped at 8 MB. Browser restrictions may require manual sharing.
Share > Link or code: provide the future published HTTPS website URL to create
a plan link, or leave it blank for an offline code. Paste either into Receive
plan and preview before confirming import. JSON imports use the same preview.
Confirming merges drawings and replaces notes/tasks/checklist in that context;
drawings from another map revision are archived. Large plans use JSON instead.
Links/codes contain the shared notes and tasks and are readable by recipients.
Tasks and checklists are included in backups and plan JSON, previewed in PNG,
and fully preserved in PDF notes. Previous features remain. Website/domain
publication is deferred. Webhook sharing does not create a Discord bot.
