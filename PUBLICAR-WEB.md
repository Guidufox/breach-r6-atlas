En Settings → Pages → Source elegir GitHub Actions. El flujo Publicar Breach publica únicamente los archivos públicos preparados por tools/build_site.py. Los cambios en main vuelven a publicar la web. No se usa un dominio propio.

Consultar revisiones de R6Calls es un flujo manual: genera paquetes con revisiones superiores, conserva el catálogo y publica los paquetes; cada usuario decide aplicarlos en su navegador.

La app guarda notas y planes en el navegador. Para pasar datos desde la versión PC, exportar e importar el respaldo. Discord utiliza un proceso separado: GitHub Pages aloja la web, pero no ejecuta el bot. El código del bot está en discord-bot; no se incluyen credenciales ni imágenes generadas.
